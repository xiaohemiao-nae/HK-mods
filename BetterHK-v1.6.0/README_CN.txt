【先说结论：怎么用最快】
  1) 把整个文件夹解压到任意位置（不用放进游戏目录）。
  2) 完全退出游戏。
  3) 双击「使用菜单.bat」，按数字选要做什么（中文界面）。

  只想装移速 x3        →  进「移速3倍」文件夹，双击 Install.bat
  只想装长椅传送        →  进「长椅传送」文件夹，双击 Install.bat
  两个都要             →  各双击一次，互不冲突

  两个功能互相独立，可以只装一个。装完照常从 Steam 启动游戏。

------------------------------------------------------------------------
  功能 A：常规水平移速 x3
------------------------------------------------------------------------
把玩家在地面 / 空中的常规左右移动速度提升为原来的 3 倍。
冲刺、跳跃、蹬墙跳、水下、碰撞、动画、受击、存档等一律不变。
形态：直接改游戏程序集里 24 个字节，装完即生效，不需要任何加载器。

适用版本：Hollow Knight 1.5.12620（Unity 6000.0.61f1）
原版 Assembly-CSharp.dll 的 SHA-256：
  e9048ef6a633970f735e01ec166d3959f610eaea7a88d827d48d67b1e5fb87bd
版本不一致时安装器会拒绝执行，不会误改任何文件。
游戏标题画面右下角可以看到版本号。

怎么确认装好了：
  双击 移速3倍\Verify.bat，出现「结论: PASS —— 补丁状态正确」即成功。
  进存档左右走两步，速度约为原来的 3 倍；空中水平速度同样 x3；
  慢走区、疾跑护符档位也同步 x3；水下速度不变。

------------------------------------------------------------------------
  功能 B：长椅互相传送（BenchWarp）
------------------------------------------------------------------------
坐在长椅上打开地图，地图上会标出其他已解锁长椅的图标；鼠标点图标即传送。
传送后角色会直接坐在目标长椅上，和正常休息完全一样（存档点随之更新）。

  游戏内操作：坐下休息 → 打开地图 → 左键点长椅图标 → 传送完成

规则：
  · 必须先坐在长椅上处于休息状态，地图上才会出现图标；
  · 没坐在长椅上时，地图完全保持原版，点击不会触发任何传送；
  · 当前坐着的那张长椅显示为灰色，不可点击；
  · 图标只出现在地图上已可见（探索过 / 买过地图）的区域里；
  · F1 = 开关左上角诊断信息，平时不需要用。

长椅清单来自游戏自己的「已遇见长椅」记录；读不到时退回内置全表，
保证功能不会因为读不到存档而变空。图标位置直接取自游戏自己的地图层级
（区域 → 场景块，块名就是场景名），所以地图缩放、拖动都不会错位。

※ 这一项不需要你装任何东西：包里已经带了编译好的 bin\BenchWarp.dll。
  双击 长椅传送\Install.bat 即可。

※ 只有当你**想改代码重新编译**时，才需要 .NET SDK：
  双击 长椅传送\InstallSDK8.bat（会自动请求管理员权限）。
  它会去微软官方接口取当时最新的 8.0 SDK，
  下载后核对 SHA-512 与官方公布值一致，再静默安装；
  已经装过 SDK 8 时会直接提示并退出，不会重复安装。

  为什么不用 winget：
  实测 `winget install Microsoft.DotNet.SDK.8` 走的是 WinHTTP，默认不经过
  系统代理，在需要代理的网络里会直接报 0x80072efd（无法与服务器建立连接），
  看起来像"下载失败"，其实是根本没走代理。InstallSDK8.bat 会自动依次尝试
  指定代理 → HTTP(S)_PROXY 环境变量 → 系统代理设置 → 直连；
  若你的代理没被自动识别，可以指定端口（端口填你自己代理软件的）：
      长椅传送\InstallSDK8.bat -Proxy http://127.0.0.1:7890

  实测环境：SDK 8.0.428 + 本机原有 .NET 8 运行时共存，编译 0 警告 0 错误。
  只装运行时（没有 SDK）是不够的 —— 运行时只能跑程序，不带编译器。

------------------------------------------------------------------------
  怎么卸载 / 恢复原版
------------------------------------------------------------------------
  移速 x3    → 双击 移速3倍\Restore.bat
               （优先用 backups\ 里的原版备份，没有备份时按字节反向还原）
  长椅传送   → 双击 长椅传送\Uninstall.bat
               （删除 DLL，并从两份清单里精确移除自己的条目）

也可以在 Steam 中对游戏点「属性 → 已安装文件 → 验证游戏文件完整性」，
两个功能都会一起还原（不会损坏游戏）。

------------------------------------------------------------------------
  找不到游戏时
------------------------------------------------------------------------
安装器会自动搜索 Steam 注册表、libraryfolders.vdf 里的所有游戏库，
以及各硬盘的常见路径。若仍提示找不到，请在该功能的文件夹里新建
game_dir.txt，第一行写游戏根目录（即包含 hollow_knight_Data 的那一层）：
  D:\SteamLibrary\steamapps\common\Hollow Knight
可参考 game_dir.example.txt。文件名必须是 game_dir.txt（去掉 .example）。
两个文件夹各有一份就各建一份，内容相同即可。

------------------------------------------------------------------------
  常见问题
------------------------------------------------------------------------
* 游戏正在运行时不要安装，DLL 可能被占用。看到「检测到游戏正在运行」，
  请先完全退出游戏再重试。
* Steam 更新游戏或「验证完整性」会把游戏文件覆盖回原版，两个功能都会失效
  （不会损坏游戏），重新分别安装一次即可。
* 原版 DLL 会自动备份到 移速3倍\backups\ 目录。请保留整个文件夹，
  不要只把单个 bat 转发给别人。
* 杀毒软件可能拦截「修改 DLL / 新增 DLL」的行为。若写入失败，
  可暂时关闭实时防护，或把本文件夹加入白名单后重试。
* 游戏装在 C:\Program Files 时写入需要管理员权限，各 Install.bat 会自动
  请求 UAC；如果 UAC 被拒绝，右键 Install.bat →「以管理员身份运行」。
* 3 倍速度下薄墙 / 单向平台偶尔可能出现高速穿透，这是引擎离散碰撞的固有
  现象，补丁没有改动任何碰撞参数。
* 长椅传送：传送会把存档点改成目标长椅（这是「坐在长椅上」的正常结果）。
  传送过程中不要强行退出游戏，等场景加载完成。
* 地图上看不到长椅图标？先确认两件事：是不是真的坐在长椅上（休息状态）、
  打开的是不是地图（不是菜单/背包）。然后看日志：
    %USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\BenchWarp.log
  · "BenchWarp v1.2.0 loaded (map-click edition)" → DLL 已加载
  · "map opened: resting=True/False"     → 地图打开被识别到了
  · "map blocks cached: N area(s), M ..." → 地图块识别成功（M=0 说明没匹配上）
  · "map click -> <场景名>"              → 点击命中，正在传送
  完全没有这个文件说明 DLL 没被加载，请跑一次 长椅传送\Status.bat 并重装。

------------------------------------------------------------------------
  安全性说明
------------------------------------------------------------------------
* 移速补丁只修改 hollow_knight_Data\Managed\Assembly-CSharp.dll 里的
  24 个字节，其余字节与所有其它游戏文件完全不动；写入前后做 SHA-256 校验，
  并用「反向恢复后哈希一致」证明没有越界改动。
* 长椅传送不修改游戏任何 DLL 里的一个字节：只新增 1 个 DLL，
  并在两份 Unity 清单末尾各追加 1 条记录；首次安装会把原始清单备份到
  backups\*.orig；卸载按条目精确移除，不依赖备份也能干净还原。
* 本压缩包不包含任何游戏 DLL（有版权，且与游戏版本强相关）。
* 所有脚本都是明文文本，可用记事本逐行审阅。各文件 SHA-256 见 SHA256SUMS.txt。
